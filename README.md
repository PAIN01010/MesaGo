# 🍽️ MesaGo

**MesaGo** es una aplicación móvil nativa desarrollada como proyecto académico para la asignatura **Desarrollo de Aplicaciones Móviles Nativas**.

La aplicación está orientada a los puntos **Tasty Food de la Universidad Laica Eloy Alfaro de Manabí (ULEAM)** y busca facilitar a la comunidad universitaria la consulta de la oferta alimenticia disponible dentro del campus.

## 🎯 Problema identificado

Los diferentes puntos Tasty Food pueden ofrecer menús distintos durante la jornada.

Actualmente, un estudiante puede necesitar desplazarse físicamente hasta un Tasty para conocer qué alimentos se encuentran disponibles, sus precios o las opciones del día.

MesaGo busca centralizar esta información para que el usuario pueda consultarla previamente desde su dispositivo móvil y decidir a qué punto dirigirse.

## 💡 Propuesta

MesaGo permitirá consultar información relacionada con los distintos Tasty Food, como:

- Menú disponible.
- Productos o platos ofrecidos.
- Precios.
- Disponibilidad.
- Ubicación del punto Tasty.

El proyecto se mantendrá con un alcance académico y se desarrollará progresivamente de acuerdo con los requisitos establecidos en la asignatura.
